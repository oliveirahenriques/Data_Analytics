Explique que a ordem é intencional: primeiro construiremos perguntas e resumos por grupo; depois escolheremos representações visuais adequadas. Todos os dados são sintéticos. Tempo: 2 min.

Motivation

The central question

How do we move from individual observations to defensible group comparisons and then communicate those comparisons visually?

Question → group → aggregate or transform → validate → encode → annotate → interpret

Diferencie cálculo de comunicação. Um resumo pode estar correto e ainda ser mal representado; um gráfico elegante pode partir de uma agregação inadequada. Tempo: 2 min.

Learning objectives

By the end of the lesson, students will be able to:

  • explain split-apply-combine;
  • group by one or more keys;
  • distinguish aggregation, transformation, filtering, and application;
  • create named aggregations, pivot tables, and cross-tabulations;
  • validate group results and denominators;
  • explain the Figure–Axes model in Matplotlib;
  • choose charts according to analytical questions;
  • use pandas, Matplotlib, and seaborn coherently;
  • produce accessible, labeled, and restrained visualizations.

Apresente os objetivos como competências observáveis. Tempo: 2 min.

Chapter 9: Plotting and Visualization

Visualization starts with a question

Question Frequent starting point
How does a value evolve? line
How do categories compare? bar or dot plot
What is the distribution? histogram, ECDF, box plot
How do two quantities relate? scatter plot
How does a matrix vary? heatmap

Chart choice follows analytical structure, not decoration.

Diga que esta tabela é orientação inicial, não uma regra absoluta. Tempo: 3 min.

The Figure–Axes model

fig, ax = plt.subplots()
ax.plot([1, 2, 3], [2, 5, 4], marker="o")
ax.set(title="A Figure contains one or more Axes",
       xlabel="Observation", ylabel="Value")
plt.tight_layout()
plt.show()
  • Figure: the complete canvas;
  • Axes: one plotting region;
  • methods on ax: plot and customize.

Evite chamar Axes de eixo. Um Axes contém os eixos x e y. Tempo: 3 min.

fig, axes = plt.subplots(1, 2)

Checkpoint 3: choose the visual encoding

Choose and justify a chart for:

  1. daily price evolution for one instrument;
  2. distribution of volume by instrument;
  3. relationship between price change and volume;
  4. weekly standardized values by instrument;
  5. category shares within each region.

Possíveis respostas: linha, box/violin, scatter, heatmap, barras proporcionais. Avalie a justificativa. Tempo: 3 min.

Accessibility and restraint

  • use sufficient contrast;
  • avoid color as the only carrier of meaning when possible;
  • label axes with units;
  • prefer direct, informative titles;
  • remove redundant legends;
  • limit annotations to relevant evidence;
  • avoid 3D effects and decorative distortion.

Conecte acessibilidade à precisão analítica. Tempo: 2 min.

Integrated Case

Analytical task

Compare weekly movement across instruments without mixing physical units.

  1. calculate daily percentage change within instrument;
  2. summarize by instrument and week;
  3. retain coverage information;
  4. validate denominators;
  5. visualize the weekly means;
  6. interpret cautiously.

A transformação percentual melhora comparabilidade de movimento, mas não cria equivalência de risco ou mercado. Tempo: 2 min.

  7. labels units and states one interpretive limitation.

Key Takeaways

Analysis-to-visualization checklist

Use como checklist reutilizável nos projetos dos alunos. Tempo: 2 min.

Main conclusions

  1. Group operations begin with a clearly defined key and observational unit.
  2. Aggregation reduces; transformation preserves; filtering selects groups.
  3. apply is a fallback for operations not clearly expressed by specialized methods.
  4. Denominators, missing keys, and coverage must be validated.
  5. Visualization translates analytical structure into visual encodings.
  6. Easy plotting does not guarantee valid comparison.
  7. Effective graphics combine correct summaries, compatible units, accessible design, and restrained interpretation.
